Hello! I'm a software engineer who loves messing around with my own small projects. I mostly professionally work in C/C++, but my personal projects are often in Python as an interpreted language is often easier to use for something small.

## Projects

### <a href="https://github.com/alexclusive/skye-net">Skye-Net</a> and <a href="https://github.com/alexclusive/skye-net-terminator">Terminator</a>

My biggest project so far is definitely <a href="https://github.com/alexclusive/skye-net">Skye-Net</a>, a Discord bot that I developed in python. I often add new features to it when I think of what to add.  

Check out the REAME in the repository for a full run-down of features, but these are my favourite parts:  
 - Train Game - Brute force the get-to-ten game with train car numbers to see different ways of getting a solution
 - Bingo - A custom bingo creator that can be used by multiple users at the same time
 - Etymology - Lookup the etymology of a word through <a href="https://www.etymonline.com/">etymonline</a>

Sometimes the machine I run Skye-Net on doesn't have enough RAM and Discord treats it as unavailable. So I developed a light weight Discord bot whose main purpose is to kill or restart Skye-Net. This is <a href="https://github.com/alexclusive/skye-net-terminator">Terminator</a>.  

As well as being able to kill and restart Skye-Net, Terminator can start up Skye-Net in the case that it crashes. It's also able to remotely check the Skye-Net log file, or check any start-up issues that Skye-Net may have faced.

### <a href="https://github.com/alexclusive/enfoldener">Enfoldener</a>

A quality of life tool that I use to manage my file system. Since setting up a Plex server requires media to be stored as follows:  

media-filename  
└── media-filename.ext

It can get quite exhausting to add files into folders of the same name hundreds of times. So I developed this tool that can be used via the windows context menu to add every file in the current directory into a new directory named appropriately.

### <a href="https://github.com/alexclusive/ytdownloader">YTDownloader</a> 

I got fed up with the amount of YouTube to mp3/mp4 websites that only let you convert a small number of videos before asking you for money, all while bombarding you with adds. I developed this tool so that I could convert videos with no ads and an unlimited number of times. This tool has a number of features that you can see through the README in the repo. I'm particularly happy with how the GUI icons turned out - I drew each myself!
